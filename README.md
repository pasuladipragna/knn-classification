# Task 6: K-Nearest Neighbors (KNN) Classification

## ✅ Objective
Implement and understand the KNN algorithm using the Iris dataset.

## 🔧 Tools Used
- Python
- Scikit-learn
- Pandas
- Matplotlib

## 💡 What’s Covered
- Feature normalization
- Tried multiple `K` values (1 to 10)
- Model evaluation: Accuracy, Confusion Matrix, Report
- Decision boundary visualization using first 2 features

## 🔬 Results
- Best Accuracy: ~97%
- Best K: 3
